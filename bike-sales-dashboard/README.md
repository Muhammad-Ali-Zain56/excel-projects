# Bike Buyers Sales Dashboard (Excel)

Interactive Excel dashboard analyzing 1,000 customer records to understand who buys bikes.

## Tools
Excel: Pivot Tables, Pivot Charts, Slicers, nested IF formulas, data cleaning

## What I did
- Cleaned raw data: expanded coded values (M/S, M/F), corrected labels, removed 26 duplicate records (1,026 → 1,000)
- Created age brackets using nested IF formulas
- Built pivot tables and pivot charts for income, age group, and commute distance
- Added slicers for marital status, region, and education

## Key findings
- Customers commuting under 1 mile were the most likely to buy a bike; those commuting 10+ miles were the least likely
- Buyers had slightly higher average income than non-buyers (Male: 60,124 vs 56,208; Female: 55,774 vs 53,440)
- Middle-aged customers were the largest group
